"GestPR" 

Ce projet sert à la calcule du prix de revient unitaite d'un article demandé.
L'utilisateur divise en 3 parties :
- le demandeur : les personnes dans l'usines. Ceux qui font la demande des articles.
- le comptabilité : les comptabilités dans le siège. Ils font le traitement de données, insèrent les informations consernant aux articles. Les résultats de calcules nous mènent à trouver le prix de revient de chacun des articles à la fin
- le validateur: ils donnent la dérnière mot , si c'est validé ou refusé.

ces utilisateurs son générer par Ldap , active directory.
Le projet récupère le nom d'utilisateur sur l'ordinateur et l'associé aveg la gestion de rôles des utilisateurs.
et chaque rôle utilisateur contient sa propre inteface.
